방법 A. 니어포드 Time to Climb로 실시간 반 전체 레이스

니어포드의 Time to Climb 활동은 학생들이 동시에 접속해 문제를 풀고, 빠르고 정확하게 맞힌 학생의 캐릭터가 산을 더 빨리 오르는 실시간 게임입니다. 아래 문항을 그대로 옮겨 넣으면 됩니다.

  1. 니어포드 레슨 편집 화면에서 Add Content & Activities → Activities → Time to Climb을 선택합니다.
  2. 테마와 문항별 제한 시간을 정합니다. (권장: 20초)
  3. 아래 문항의 복사 버튼을 눌러 질문과 보기를 붙여넣고, 정답(초록색)을 체크합니다.
  4. 캠프(단원)별로 Time to Climb을 나누어 넣으면 개념 슬라이드 → 게임 → 개념 슬라이드 → 게임 순서로 진행할 수 있습니다.

방법 B. 이 게임을 니어포드 슬라이드에 넣기

  1. 이 HTML 파일을 GitHub Pages 등에 올려 웹 주소(URL)를 만듭니다.
  2. 니어포드 레슨에서 Add Content → Web Content를 선택하고 그 주소를 붙여넣습니다.
  3. 학생은 각자 기기에서 개념 학습 → 등반 게임을 합니다.
  4. 게임이 끝나면 📋 내 기록 복사하기를 눌러, 바로 뒤에 넣은 Collaborate Board(또는 개방형 질문)에 붙여넣게 하면 반 전체 기록을 한눈에 비교할 수 있습니다.
  5. 제한 시간은 주소 뒤에 ?time=180처럼 초 단위로 붙여 바꿀 수 있습니다. (기본 600초) 예) …/진화_등반게임.html?time=300

※ 방법 B는 학생마다 따로 플레이합니다. 반 전체 실시간 순위가 필요하면 방법 A를 쓰세요.
